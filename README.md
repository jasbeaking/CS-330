# CS 330 Final Project Portfolio

This repository contains my final project for **CS 330 – Computational Graphics and Visualization**. It demonstrates my ability to create a fully realized 3D scene and showcases the design and development decisions behind it.  

## Project Components

- **3D Scene ZIP Folder** – Includes all assets, code, and resources for the recreated 3D desk scene.  
- **Design Decisions Document** – Explains the reasoning behind object choices, scene layout, lighting, and development techniques.  

## Reflection

### Designing Software
My approach to software design begins with understanding the problem and breaking it into manageable components. This project helped me strengthen skills in **object-oriented design**, **scene organization**, and **systematic planning**.  

I followed an iterative design process:  
- Planning the scene layout  
- Creating individual objects  
- Refining interactions  

These strategies—like **prototyping** and **documenting design choices** will help in future projects where complex systems need to be well-organized and maintainable.

### Developing Programs
When developing the 3D scene, I focused on:  
- **Incremental building**  
- **Modular coding**  
- **Continuous testing**  

Iteration was key; I tested object placement, lighting, and camera controls repeatedly, improving each version. Across the milestones, my workflow evolved from basic rendering to fully interactive scene management, which was critical to achieving the final project.

### Skills and Applications
Working on this project reinforced my understanding of how computer science allows me to solve complex problems and create interactive, visual experiences. Computational graphics taught me:  
- **3D modeling**  
- **Shader management**  
- **Camera and lighting control**  
- **Interactive scene design**  

These skills are valuable for future coursework and projects, and professionally, they prepare me for careers in **3D visualization, virtual reality, game development, and interactive media**.
